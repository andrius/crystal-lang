# CLAUDE.md

Crystal-lang development images with icr (Crystal REPL, like Ruby irb), including Asterisk-paired variants. Own repo (Andrius).

- Base: crystallang/crystal + alpine variants. Per-version files: `Dockerfile-0.30.1` .. `Dockerfile-0.34.0`, `Dockerfile-asterisk-11/13/16`, `Dockerfile-latest`.
- Build via `./build.sh`.
- Last commit: 2019-09-25.
